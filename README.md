# 🖧 IPGetter

**A Java-based domain-to-IP resolver built with NetBeans.**

## 🌐 Overview

IPGetter is a simple tool that takes a domain name and returns its current IP address.  
Useful for networking tasks, DNS lookups, or basic educational use.

### 🧪 Example

```
google.com → 142.250.64.78
```

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Daxxtropezz/IPGetter.git
   ```

2. **Open the project in NetBeans.**

3. **Build and run the main class.**

4. **Input a domain to retrieve its IP address.**
